# HiPerGator Access: RAI Lab Resources

Public English tutorial website for requesting HiPerGator access to RAI Lab sponsored resources at Florida State University.

The page summarizes the UF Research Computing account-request workflow. The current UFRC documentation controls if the workflow changes.

## Local preview

Open \`index.html\` in a browser.
